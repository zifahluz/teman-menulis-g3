# Teman Menulis Peringkat G3

Portal ulang kaji karangan Bahasa Melayu G3 yang percuma dan tanpa API.

## Kandungan
- Bank soalan daripada dokumen `Bank_Soalan_Karangan_BM_G3_Gabungan.docx` yang dibekalkan.
- Panduan per soalan: kehendak, rangka, soalan perancangan, frasa, kesilapan dan semakan kendiri.
- Soalan yang dilabel tahun tidak semestinya disahkan sebagai soalan rasmi.
- Panduan menggunakan rangka pedagogi dan mesti disemak oleh guru sebelum digunakan secara meluas.

## Penerbitan percuma
1. Cipta repositori GitHub awam.
2. Muat naik `index.html` dan `questions.json` ke akar repositori.
3. Settings → Pages → Deploy from a branch → main / (root).
4. Akses laman di URL GitHub Pages repositori.

Tiada automasi berkala atau API diperlukan: keseluruhan bank panduan tersedia sebaik laman diterbitkan. Kemas kini dengan mengubah `questions.json` dan commit ke GitHub.
